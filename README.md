# Heart Disease Analysis

A data analytics and visualization project focused on exploring heart disease data to identify key patterns, trends, and risk factors. This project combines exploratory data analysis in Python with an interactive Power BI dashboard to present insights in a clear and meaningful way.

## Project Overview

The goal of this project is to analyze heart disease-related data and understand how different health indicators may be associated with heart disease. The project includes:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA) using Python
- Interactive dashboard development in Power BI
- Final project report and presentation

This repository was created as part of a group academic project.

## Objectives

- Explore the structure and quality of the dataset
- Identify important variables related to heart disease
- Visualize trends and patterns in patient health data
- Build a dashboard for easy interpretation of results
- Summarize findings in a project report and presentation

## Repository Contents

- `EDA_Notebook.ipynb` – Python notebook for data cleaning, preprocessing, and exploratory data analysis
- `Group_8_ Dashboard.pbix` – Power BI dashboard file
- `Heart Disease Analysis – Comprehensive Project ReportGroup 8.pdf` – Final project report
- `merged_dataset_cleaned.zip` – Cleaned dataset used in the analysis

1. Collected and prepared the heart disease dataset

3. Performed exploratory data analysis in Python

6. Documented findings in the final report and presentation

## Key Analysis Areas

The project focuses on analyzing variables such as:

- Age
- Gender
- Blood pressure
- Cholesterol
- Chest pain type
- Heart rate
- Other medical indicators related to heart disease

## Dashboard Highlights

The Power BI dashboard helps users explore:

- Distribution of heart disease cases
- Patient demographics
- Relationships between medical factors and heart disease
- Visual summaries for better decision-making
